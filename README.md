# BedrockFeel

مود Fabric للكلاينت فقط (Minecraft 1.20.1). ينقل أنيميشنات البيدروك للجافا بصريًا. السيرفر ما يحتاج أي شي، ويشتغل على أي سيرفر لأنه يغيّر الرسم عندك بس.

## الحالة الحالية (صريحة)

| الميزة | الحالة |
|---|---|
| swing اليد (ضربة، منظور ثالث) | مكتوبة من ملفات البيدروك الرسمية، غير مجرّبة داخل اللعبة |
| وضعية الإلتيرا (واقف وسحب) | مكتوبة، غير مجرّبة |
| الإلتيرا وهي طايرة | الجافا والبيدروك نفس الأرقام أصلًا، ما تغيّرت |
| السحب (sneak) والـ bob | تقريبًا متطابقة أصلًا بين النسختين |
| تسجيل سرعة الإلتيرا والـ firework (زر J) | جاهز للمعايرة |
| السباحة والزحف (swim/crawl) | لسه، القيم موجودة في `BedrockConstants.java` |
| منظور أول (اليد والعنصر) | لسه |
| فيزياء الإلتيرا والـ firework نفسها | لسه، لازم قياسات من البيدروك |

الكود كُتب بدون ما أقدر أبنيه أو أشغّله (بيئتي ما توصل لـ Fabric Maven)، فمتوقع أول بناء يعطيك خطأ أو اثنين في أسماء الـ mixins. الصق لي الخطأ وأصلحه.

---

## 1) تجهيز البيئة

1. نزّل **JDK 17** (مثلًا Temurin 17). تأكد: `java -version` يعرض 17.
2. نزّل **IntelliJ IDEA Community** (الأسهل مع Fabric).
3. نزّل **Git**: https://git-scm.com
4. سوّ حساب على https://github.com

## 2) أول مرة: Gradle wrapper

المجلد ما فيه `gradlew`. افتح الترمنال داخل مجلد المشروع ونفّذ مرة وحدة (لازم Gradle منصّب):

```
gradle wrapper --gradle-version 8.5
```

أو أسهل: افتح المشروع في IntelliJ (File > Open > مجلد bedrockfeel) وهو بيسوي الـ wrapper تلقائيًا ويحمّل Minecraft والـ mappings. أول مرة تاخذ كم دقيقة.

## 3) تشغيل وتجربة

داخل IntelliJ: تبويب Gradle > Tasks > fabric > `runClient`. تفتح لك ماينكرافت 1.20.1 ومعها المود. ادخل أي عالم أو سيرفر وجرّب:

- اضرب بالهواء ولاحظ حركة الجسم واليد.
- البس إلتيرا، وقف وبعدين اسحب (shift) وشوف الأجنحة من منظور ثالث (F5).
- اضغط J لبدء تسجيل الطيران (ملف `bedrockfeel-flight.csv` في مجلد اللعبة).

## 4) بناء ملف المود (.jar)

```
./gradlew build
```

الملف يطلع في `build/libs/bedrockfeel-0.1.0.jar`. حطه في `.minecraft/mods` مع **Fabric Loader 0.15.x** و **Fabric API 0.92.2+1.20.1**.

## 5) رفعه على GitHub بالتفصيل

1. في github.com اضغط **New repository**، سمّه `bedrockfeel`، خله Public أو Private، لا تحط README (عندك واحد).
2. افتح ترمنال داخل مجلد المشروع:

```
git init
git add .
git commit -m "Initial commit"
git branch -M main
git remote add origin https://github.com/اسمك/bedrockfeel.git
git push -u origin main
```

3. أي تعديل بعدها:

```
git add .
git commit -m "وصف التعديل"
git push
```

4. لو طلب تسجيل دخول: GitHub ما يقبل كلمة السر العادية. سوّ **Personal Access Token** من Settings > Developer settings > Personal access tokens، واستخدمه مكان كلمة السر. أو نزّل GitHub Desktop وخلّه يتولى الموضوع.
5. ملف `.gitignore` موجود فيه عشان ما ترفع `build/` و`.gradle/` و`run/`.

## 6) شلون تعدّل المود

- **القيم** كلها في `BedrockConstants.java`. لو الـ swing يلف باتجاه غلط غيّر `YAW_SIGN` من `1.0f` إلى `-1.0f`.
- **الأنيميشن** في `mixin/PlayerModelMixin.java`. نحقن بعد `super.setAngles` عشان الأكمام والجاكيت تتبع الحركة.
- **الإلتيرا** في `mixin/ElytraModelMixin.java`.
- المرجع الأصلي: `resource_pack/animations/player.animation.json` في https://github.com/Mojang/bedrock-samples. كل صيغة في الكود لها اسم أنيميشن في التعليق.
- كيف تعرف اسم دالة أو حقل: في IntelliJ اضغط Ctrl+Click على أي كلاس ماينكرافت، والأسماء بنظام **Yarn**.

## 7) الخطوة اللي تجيبها أنت: فيديو القياس

لفيزياء الإلتيرا والـ firework ما فيه ملف منشور. سوّ التالي في البيدروك والجافا بنفس الظروف (نفس الاتجاه، نفس الفيرورك، نفس النقطة):

1. طير بإلتيرا بزاوية ثابتة (مثلًا مباشرة للأمام) واستخدم فيرورك.
2. في الجافا اضغط J للتسجيل وأرسل لي ملف الـ CSV.
3. في البيدروك فعّل Show Coordinates وصوّر الشاشة بدقة 60fps، وأرسل لي الفيديو أو سجّل الإحداثيات كل ثانية.

بالفرق بين الاثنين أضبط قيم الدفع.

## ملاحظة

المود كلاينت فقط ويغيّر مظهر وحركة الجسم عندك. أي تغيير مستقبلي في حركة الإلتيرا الفعلية بيكون مبني على المقارنة، وبعض السيرفرات اللي فيها anti-cheat ممكن تعتبره شاذ، فجرّب بس في السيرفرات اللي فاهم قوانينها.
